## 가족 동선 제안 (시간 없이, 장소만)

1. **리조트에 남을 때:** 마마티라(샷·뷰) → 웰컴센터 빵 포장 또는 해변 걸어 트리고/보사노바.
2. **해변 카페+빵:** 교동빵집 오픈 후 포장 → 트리고 또는 곳간에서 커피. 아이 있으면 곳간 망고빙수/스무디 또는 트리고 메밀 아이스크림.
3. **덕산·덕봉산:** 탐방로 → 리가브로. 모래놀이면 칠랙스.
4. **장호/레일바이크 가는 날:** 궁촌 파로라 또는 용화찬미 → 장호 클리어비치. 장호 주차는 역·공영 먼저.
